# 曲线季节性重点品种敏感性复核

对原全品种筛查中的 JD、RU、M、RB，使用相同真实合约快照对比：当日线性与二次期限拟合、30—540天与60—365天期限范围、合约成交量及持仓量至少达到当日该品种最大值的0.1%、0.5%、1%。期限拟合和流动性筛选都在形成交割月年度面板之前完成。

```powershell
python scripts/audit_curve_seasonality.py --snapshot-dir results/all_commodity_curves
```

输出 `curve_seasonality_audit/sensitivity.csv` 与 `delivery_month_profiles.csv`。表中的 p 值是对已选出的四个重点品种及各个敏感性设定的描述性复核，**不是重新对全商品宇宙进行发现检验，也没有为所有尝试过的设定做多重比较校正**。

2026-09-30 已有数据的主要发现：改用二次曲线和缩窄期限后，四品种的原信号都未消失。但加入相对流动性筛选后，JD、M 仍有正的样本外改善，测试年数明显减少；RU 对门槛较敏感，1% 门槛下不足以完成测试；RB 在0.1%门槛下样本外 R² 下降至约0.037，0.5%及1%门槛下测试年份不足。故原曲线显著性不能直接等同于可交易合约上的季节规律。当前仍未验证真实成交成本、月间套利可执行性，或对 carry 策略绩效的净影响。
