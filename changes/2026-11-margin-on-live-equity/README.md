# 2026-11 保证金基准改为账户实际权益

## 为什么改

原生账户的仓位公式原来是 `名义 = 初始资金 C0 × 杠杆 × 敞口`、`保证金预算 = 50% × C0`，
`C0` 固定为 5000 万、不随权益复利。账户盈利后权益涨到 5.7 倍，但敞口仍锁在 5000 万的
量级，等于**仓位相对权益越做越小**，实现波动从 2016 年的 25.4% 一路衰减到 2023 年的
5.3%、2024 年的 6.3%，20% 的波动目标名存实亡。

## 修正后的口径

- 名义敞口 = `当日权益 E(t) × 杠杆 × Σ_sleeve(0.25 × signal / 当日该 sleeve 品种数)`
- 手数 = `trunc(E(t) × 敞口 / (结算价 × 合约乘数))`，每日开盘用当次权益
- 保证金预算 = `50% × E(t)`，超出时同比例缩后再 `trunc`
- 其余不变：50% 保证金预算、1 跳滑点、25% 量上限、逐笔原生手续费、收盘盯市
